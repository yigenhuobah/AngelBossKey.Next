# 天使老板键 Next

天使老板键 Next 是面向 Windows 10 22H2 和 Windows 11 x64 的窗口隐藏工具。它可以用一个全局热键隐藏指定程序的窗口，再按一次恢复；也支持应用静音、自动触发、按需提权和独立隐私桌面。

核心功能使用 Windows 正式 API，不注入其他进程、不远程写内存、不联网，也不默认申请管理员权限。程序采用自包含便携发布，无需安装。

## 第一次使用

1. 打开 `dist\AngelBossKey.Next-v0.8.0-win-x64`，运行 `AngelBossKey.Next.exe`。
2. 先打开准备隐藏的程序，再回到天使老板键 Next，点击“添加程序”。
3. 在窗口列表中勾选目标并确认。添加的是该程序的可执行文件规则，不只是当时选中的单个窗口。
4. 点击右上角的热键按钮，按下“至少一个修饰键 + 一个普通按键”，例如 `Ctrl+Alt+H`，然后保存。
5. 点击“隐藏目标”进行第一次测试；确认目标消失后，再按刚设置的热键恢复。

软件没有默认热键。当前场景必须成功注册热键后，隐藏按钮和隐藏功能才会启用。若组合键已被 Windows 或其他软件占用，界面会提示注册失败，并保留原来的有效热键。

> 建议首次测试时先添加记事本等普通程序，确认隐藏和恢复都正常，再配置工作软件、游戏或管理员权限程序。

## 日常使用

- 按当前场景的全局热键：第一次隐藏，再按一次恢复。
- 双击托盘图标：显示主界面。
- 右键托盘图标：可以切换场景、显示主界面、隐藏/恢复当前场景或退出。
- 点击窗口右上角关闭按钮：默认只是收起到托盘，并不会退出。
- 从托盘选择“退出”：程序会先恢复由它隐藏的窗口和修改过的音频状态，再退出。

隐藏时会保存窗口原来的普通、最小化或最大化状态。隐藏期间，目标程序新建的顶层窗口也会立即加入隐藏集。恢复时只恢复仍符合当前有效规则的窗口；停用、临时排除或删除某条规则，会只恢复不再匹配的那部分窗口。

## 主界面选项

### 顶部状态和操作

| 选项 | 用途 |
| --- | --- |
| 状态文字 | 显示“保护就绪”“目标已隐藏”或“独立桌面已启用”，下方会显示最近一次操作结果和失败数量。 |
| 热键按钮 | 设置当前场景的全局热键。必须包含 `Ctrl`、`Alt`、`Shift` 或 `Win` 中至少一个修饰键，再加一个普通按键。每个场景可以设置不同热键。 |
| 隐藏目标 / 返回恢复 | 不用热键也能手动执行当前场景。普通场景隐藏目标窗口；独立桌面场景切换桌面；隐藏后按钮会变为“返回 / 恢复”。 |

### 场景

场景是一组独立的热键、目标规则、自动化设置和工作模式。例如可以创建“办公”“直播”“演示”三个场景，分别管理不同程序。

| 选项 | 用途 |
| --- | --- |
| 场景下拉框 | 切换当前正在编辑和手动操作的场景。所有已配置场景的热键都会在程序运行时注册。 |
| `+` 新建场景 | 创建一套空白配置，需要单独添加目标并设置热键。 |
| 场景操作菜单 | 可复制当前场景、导入或导出单个场景、试运行 5 秒，以及查看全部场景的热键。复制和导入的场景不会沿用原热键，避免注册冲突；导入的启动项默认禁用，复核路径和参数后再手动启用。 |
| 删除按钮 | 删除当前场景及其配置。至少会保留一个场景；正在隐藏时应先恢复再调整场景。 |
| 场景名称 | 修改下拉框中显示的名称，输入完成并移开焦点后保存。 |
| 独立隐私桌面 | 将当前场景改为独立 Desktop 模式，而不是逐个隐藏目标窗口。勾选后可以选择右侧的桌面模式。详细限制见“独立隐私桌面”。 |
| 完整桌面（Explorer） | 默认模式。尝试在独立 Desktop 启动并验证完整的 Windows Explorer 任务栏和桌面；失败时自动回退到兼容轻量 Shell。 |
| 兼容桌面（轻量） | 跳过 Explorer，直接使用天使老板键 Next 自带的轻量 Shell。界面更简单，但启动和返回路径更可控。 |

### 自动化

| 选项 | 用途 |
| --- | --- |
| 空闲 N 分钟 | 键盘和鼠标达到指定空闲时间后自动隐藏当前场景。填 `0` 表示关闭。它只会自动隐藏，不会因继续空闲而自动恢复。有效范围为 0 到 1440 分钟。 |
| 鼠标触发 | 可选择侧键 1、侧键 2、中键、滚轮向上或滚轮向下，用该动作切换隐藏/恢复。选择“关闭”表示不用鼠标触发。 |
| 冷却 | 两次自动化触发之间的最短间隔，单位为毫秒，用来防止滚轮或侧键连续触发导致刚隐藏又恢复。有效范围为 250 到 60000 毫秒，默认 1000。 |
| 启用低级鼠标钩子 | 鼠标侧键、中键和滚轮触发必须勾选此项才会生效。普通全局热键和空闲检测不需要它。 |
| 暂停自动化 | 暂停空闲和鼠标触发，仅对本次运行有效；手动按钮和场景热键仍可使用。重新启动程序后会恢复自动化。 |
| 按需提权 | 遇到管理员权限窗口时，临时启动一次 Elevated Broker 并显示 UAC。主程序本身不会整体提权，Broker 完成一次查询、隐藏或恢复请求后退出。此项是所有场景共用的设置。 |

低级鼠标钩子必须由用户显式开启。若已经选择了鼠标动作但没有勾选“启用低级鼠标钩子”，保存后鼠标触发会按关闭处理。

### 目标程序和规则

点击“添加程序”会列出当前可选择的顶层窗口，包括图标、程序名、窗口标题和可执行文件路径。列表支持搜索、刷新和点击列标题排序；可一次选择多个程序，同一路径不会在同一场景中重复添加。

默认情况下，一条规则会匹配同一可执行文件产生的全部顶层窗口。例如从浏览器中选择一个窗口，通常会匹配该浏览器进程路径下的其他窗口，而不只匹配选中时的标题。

| 选项 | 用途 |
| --- | --- |
| 启用 | 持久启用或停用这条规则。取消勾选后，该程序以后不会随场景隐藏；如果当前已隐藏，只恢复该规则不再覆盖的窗口。 |
| 程序 / 状态 | 显示程序图标、名称以及“已启用”“已停用”“本次运行已排除”或“路径失效”。路径失效的规则不会执行。 |
| 标题包含 | 可选条件。留空时匹配该程序的所有标题；填写文字后，只匹配标题中包含该文字的窗口，不区分大小写。 |
| 标题排除 | 可选条件。标题中包含这里所填文字的窗口不会匹配，不区分大小写。它会在“标题包含”条件之后继续过滤。 |
| 可执行文件 | 实际用于识别程序的完整路径，只读显示。程序升级或移动导致路径不存在时，需要删除旧规则并重新添加。 |
| 静音 | 隐藏该规则匹配的程序时，按进程静音其 Core Audio 会话。恢复时精确还原原音量和原静音状态，不修改系统总音量；隐藏期间新建的目标音频会话也会静音。 |
| 临时排除 | 本次运行暂时不执行该规则，适合临时保留某个程序。它不会写入设置；重启后自动取消。隐藏期间勾选时，只恢复该程序对应的窗口和音频状态。 |
| 上移 / 下移 | 调整列表顺序，便于管理。目前所有规则按“任意一条匹配即生效”处理，顺序不代表优先级。 |
| 移除 | 永久删除该场景中的规则。若窗口当前已隐藏，会恢复删除后不再被其他规则匹配的窗口。 |

标题条件适合一个程序同时开着不同用途窗口时使用。例如“标题包含”填写“项目 A”，只隐藏标题中有“项目 A”的窗口；再填写“标题排除”为“会议”，则标题同时含有“会议”的窗口会保留。

在目标表格中选中多行后右键，可以批量启用、停用、临时排除、取消排除、开启静音、关闭静音或移除规则。批量修改与逐行修改遵循相同的恢复语义。

### 独立桌面启动项

“工作区启动项”用于管理进入独立隐私桌面时自动打开的程序，也可以作为独立桌面顶部工具栏或轻量 Shell 中的收藏入口。

| 选项 | 用途 |
| --- | --- |
| 启用 | 控制该启动项是否参与自动启动和收藏菜单，不删除其配置。 |
| 名称 | 在启动项列表和独立桌面收藏菜单中显示的名称。 |
| 可执行文件 | 要启动的程序完整路径。路径失效时不会启动，并会在状态中提示。 |
| 参数 | 可选命令行参数，例如指定文件、项目或程序自身的启动模式。程序路径会单独传给 Windows，不需要再加引号。 |
| 工作目录 | 可选启动目录。留空时使用可执行文件所在目录；相对路径建议由目标程序自己处理。 |
| 添加 | 从文件选择器添加一个程序，可继续编辑名称、参数和工作目录。 |
| 捕获运行程序 | 把当前独立工作区中正在运行且可识别路径的应用加入启动项，已存在的路径会跳过。适合先手动布置工作区，再保存为下次启动布局。 |
| 关闭工作区 | 返回原桌面并结束该独立工作区中的 Explorer、工具栏及应用。未保存内容会丢失，执行前会再次确认。 |

启动项只在该场景的工作区第一次创建时自动运行。普通“返回”会保留工作区和其中的应用，再次进入不会重复启动；“关闭工作区”才会结束这些进程。场景切换遇到仍有应用的保留工作区时会拒绝切换，避免误关工作。

### 底部选项

| 选项 | 用途 |
| --- | --- |
| 日志图标 | 打开 `%LocalAppData%\AngelBossKey.Next\logs`，用于排查热键、窗口、音频、提权和独立桌面问题。诊断日志不记录窗口标题。 |
| 开机启动 | 为当前 Windows 用户写入启动项，登录后以 `--background` 参数运行，不需要管理员权限。已有有效热键时不会弹出主窗口；尚未设置热键时仍会显示界面提醒配置。 |
| 关闭到托盘 | 勾选时，点击主窗口关闭按钮只隐藏界面，功能继续运行；取消勾选时，点击关闭按钮会恢复全部状态并真正退出。 |

## 独立隐私桌面

“独立隐私桌面”使用 Win32 Desktop API 创建与当前桌面隔离的工作区。它不是 Windows 任务视图中的虚拟桌面，也不会把当前已经打开的窗口搬到新桌面。

独立桌面提供两种 Shell：

- “完整桌面（Explorer）”：在新 Desktop 中启动独立 `explorer.exe`，只有检测到同一 Desktop 上属于该 Explorer 的 `Shell_TrayWnd` 任务栏和 `Progman` 桌面后才允许切换。可选的右上角紧凑菜单提供场景名称、收藏程序、返回和关闭工作区；不需要时可在场景设置中取消“右上角菜单”，再用场景热键或 `Ctrl+Alt+Shift+F12` 返回。外观和使用方式最接近原版。
- “兼容桌面（轻量）”：使用天使老板键 Next 自带的全屏 Shell，不依赖 Explorer。它提供时钟、“打开程序”、收藏程序、记事本、计算器、命令提示符、“返回原桌面”和“关闭工作区”等入口。独立桌面中的程序会保留到再次进入或主动关闭工作区。

两种模式都可以再次按当前场景热键返回。兼容桌面始终提供可见返回入口；完整桌面仅在启用右上角菜单时提供可见入口。`Ctrl+Alt+Shift+F12` 是不依赖场景配置的紧急返回热键，在菜单关闭、Shell 或前台程序无响应时使用。

独立桌面中的 Explorer 和由它启动的程序归天使老板键 Next 管理。返回原桌面时它们会保留，便于再次进入；主界面会显示工作区运行程序数。主动关闭工作区、退出或强制结束天使老板键 Next 时会一并关闭。程序退出前若检测到工作区仍有应用，会先提示保存工作。

选择完整桌面后，如果 Explorer 被单实例机制重定向、提前退出，或在 12 秒内没有创建完整任务栏与桌面，软件不会切换到空桌面，而是自动启动兼容轻量 Shell。只有两种 Shell 都失败时，才按该场景目标规则回退为普通窗口隐藏。

成功进入任一种独立桌面时，都不会执行该场景目标列表中的普通窗口隐藏和应用静音；目标列表只用于两种 Shell 都无法启动时回退为普通隐藏。没有可用目标规则时，失败会直接留在原桌面并报告原因。

兼容模式看不到 Windows 任务栏和原桌面图标属于正常设计，不是黑屏。完整模式虽然使用 Explorer，但开始菜单、通知中心、现代应用和系统组件仍可能绑定默认桌面，不能等同于完整登录会话。

以下环境不保证兼容：反作弊软件、独占全屏程序、系统 UAC 安全桌面及其他系统安全桌面。检测到全屏前台窗口时，软件会拒绝切换，避免无法返回。

## 管理员权限窗口

普通权限程序不能直接控制管理员权限窗口，这是 Windows 的权限边界。

- 未勾选“按需提权”时，这些窗口会保持可见，界面会报告未处理数量，不会静默假装成功。
- 勾选“按需提权”后，只有确实需要处理高权限窗口时才显示 UAC，并使用短生命周期 Broker 完成本次操作。
- 如果拒绝 UAC、目标权限更高或系统策略阻止操作，该窗口仍会保持可见并显示失败结果。

## 恢复和排错

### 热键没有反应

先确认右上角显示的是具体组合键，而不是“设置热键”。若设置时提示冲突，请换一个较少被占用的组合。场景热键在所有程序窗口外也能生效，但软件必须仍在运行。

### 程序没有被隐藏

检查规则是否为“已启用”，是否勾选了“临时排除”，路径是否显示“路径失效”，以及标题包含/排除条件是否写反。管理员窗口还需要启用“按需提权”并通过 UAC。

### 鼠标动作没有触发

除了选择“鼠标触发”的动作，还必须勾选“启用低级鼠标钩子”。如果刚触发过一次，请等待“冷却”时间结束；同时确认没有勾选“暂停自动化”。

### 独立桌面没有进入

先退出独占全屏程序，再尝试切换。完整 Explorer 初始化失败会先自动回退到兼容轻量 Shell；轻量 Shell 也无法完成验证时才取消切换，有目标规则时会继续回退为普通窗口隐藏。详细原因可在界面底部消息和诊断日志中查看。

### 软件被强制结束后窗口仍然不见

隐藏前，程序会先原子写入窗口和音频恢复记录。重新启动同一路径下的天使老板键 Next，它会验证窗口句柄、进程 ID、进程启动时间等身份后自动恢复。不要手动删除 `recovery.json` 或 `audio-recovery.json`，除非已经确认不再需要恢复。

通过托盘“退出”或关闭主窗口正常退出时，软件会先执行恢复。Windows 关机或注销时，为避免系统强制结束进程导致恢复记录损坏，软件会保留恢复日志，并在下次启动时验证身份后继续处理。

### 重复启动程序

软件只允许一个实例运行。再次启动 `AngelBossKey.Next.exe` 会唤醒已有实例的主界面，不会启动第二套热键和托盘图标。

## 本地数据和隐私

设置、恢复数据和诊断日志保存在 `%LocalAppData%\AngelBossKey.Next`：

- `settings.json`：场景、热键、规则、自动化及启动选项。
- `recovery.json`：隐藏窗口的身份和原始显示状态，恢复完成后删除。
- `audio-recovery.json`：被修改音频会话的原始状态，恢复完成后删除。
- `logs\angelbosskey.log`：不含窗口标题的滚动诊断日志，最多保留三份备份。

程序不发起网络请求，也不包含遥测。开机启动使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，命令包含程序绝对路径和 `--background` 参数。移动程序目录后，下次正常启动会自动修复启动路径。

## v0.8 功能概览

- 多场景配置，每个场景拥有独立热键、目标规则、自动化、工作模式和独立桌面启动项。
- 托盘快速切换场景，支持场景复制、单场景导入导出、5 秒试运行及热键总览。
- 按可执行文件和可选标题条件匹配窗口，隐藏期间持续处理新窗口。
- 窗口选择器支持搜索、排序和刷新；目标规则支持多选批量操作。
- 保留原窗口显示及前台状态，支持正常退出恢复和异常重启恢复。
- 按进程静音、空闲自动隐藏、显式启用的鼠标触发及运行期暂停。
- 托盘常驻、单实例、当前用户开机启动和 Explorer 重启后的托盘恢复。
- 可选短生命周期 Elevated Broker，以及带完整 Explorer/兼容轻量 Shell 的 Win32 独立 Desktop 模式。

dotnet build .\AngelBossKey.Next.slnx -c Release

提交代码前运行统一质量门禁：

```powershell
.\eng\quality.ps1
```

发布输出位于 `dist\AngelBossKey.Next-v0.8.0-win-x64`。运行 `AngelBossKey.Next.exe` 即可，无需安装。自包含包固定携带稳定版 .NET 10.0.10 运行时。
